## 1. Password hash, login parsing, and session cookie

No earlier group. These modules stay free of Express, the Worker, and MongoDB. Tests live in `src/auth.test.js` and are added to the root `npm test` script in the same tasks that create them.

- [ ] 1.1 Add `src/password.js` with `hashPassword(plain)` and `verifyPassword(plain, stored)`. Use `node:crypto` `pbkdf2` (SHA-256, 100000 iterations, 16-byte salt, 32-byte digest) and store `pbkdf2-sha256$100000$<base64url salt>$<base64url digest>` as in `design.md` decision 3. Trim the plaintext. `verifyPassword` returns false for a bad shape or a mismatch and uses `timingSafeEqual` on equal-length buffers. Add `src/auth.test.js` covering a round trip, a wrong password, a tampered digest, and a non-string stored value. Add `src/auth.test.js` to the `test` script in `package.json` beside the existing files. Verify with `npm test` from the repo root.
- [ ] 1.2 Add `src/loginInput.js` with `parseLoginBody(body)` implementing the identifier and password table in `design.md` decision 5. Accept one of `username`, `email`, or `account`. An `account` value that contains `@` is an email lookup. Otherwise it is a username lookup. Throw `Error` with `.status` 400 and the exact `error` sentences from that table (`Body must be a JSON object`, `Username or email is required`, `Provide one username or email`, `Username is invalid`, `Email is invalid`, `Password is required`). Username pattern is `^[A-Za-z0-9._-]{1,64}$`. Email is trimmed, at most 254 characters, one `@`, and non-empty sides. Extend `src/auth.test.js` for a username, an email, an `account` of each kind, both-blank, both identifiers, `[]`, `null`, and a whitespace password. Verify with `npm test`.
- [ ] 1.3 Add `src/session.js` with `signSession`, `verifySession`, `readCookie`, and `sessionCookieHeader` from `design.md` decision 4. Cookie name `admin_session`. Lifetime 28800 seconds. `Secure` only when the caller passes `secure: true`. The clear header uses `Max-Age=0`. `verifySession` returns `null` for a bad MAC, a bad shape, or `exp <= now`. Honor the `nowMs` argument. Extend `src/auth.test.js` for a round trip, a tampered signature, an expiry one second in the past, a missing cookie, an HTTPS header that contains `Secure`, and an HTTP header that does not. Verify with `npm test`.
